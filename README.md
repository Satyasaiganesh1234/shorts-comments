
# Shorts Comments — Kept in the Moment

A UX/UI design concept for making the YouTube Shorts commenting experience more intuitive, accessible, and convenient.

The project explores how viewers can read, react to, and participate in conversations without losing their place in the video.

> This is an independent concept project and is not affiliated with or endorsed by YouTube. The prototype uses illustrative sample comments and does not represent a production application.

## Project Overview

Opening comments on a short-form video can interrupt the viewing experience. This project proposes a mobile commenting interface that keeps the video visible while allowing users to explore conversations.

The concept focuses on:

- Maintaining video continuity while viewing comments.
- Making comment threads easier to navigate.
- Simplifying writing and replying to comments.
- Supporting accessibility and different screen sizes.
- Providing clear feedback for loading, error, and offline states.

## Features

### Comment Interaction
- View comments in a mobile bottom sheet.
- Switch between Top and Newest sorting.
- Expand and collapse reply threads.
- React to comments.
- Write comments and replies.
- Access comment reporting options.

### User Experience
- Return to the same video position after closing comments.
- Keep the video visible while browsing conversations.
- Provide loading, empty, error, offline, and disabled-comment states.
- Preserve draft text during common interruptions.

### Accessibility
- Large touch targets and readable typography.
- Support for screen readers and keyboard navigation.
- Clear interaction labels and focus states.
- Consideration for larger text and reduced motion.

## Prototype

The project includes a self-contained HTML prototype that demonstrates the proposed interaction flow.

### How to Run

1. Clone or download this repository.
2. Open the `shorts-comments-prototype.html` file in a web browser.
3. Interact with the prototype using the available controls.

No additional installation is required.
